# 东京垃圾分类

[查看 Word 原件](./东京垃圾分类.docx)

写于2026年9月8号，小平市，一桥寮。

日本的垃圾分类非常细致，根据宿舍分发的垃圾分类指南。丢垃圾时要将垃圾分为大约10种，可燃垃圾（燃やすごみ），不可燃垃圾（燃やさないごみ），塑料容器包装（プラスチック製容器包装），资源垃圾（資源），粗大垃圾（粗大ごみ），有些地方还会专门分类厨余垃圾。实际的垃圾分类还会更加细致，比如资源垃圾小类中的瓶子和罐子归属于不同的垃圾桶，饮料的标签和瓶盖和瓶子都要分开扔。也就是说，一个正常的设施中至少需要四到五种垃圾桶，用以分类不同的垃圾。如果我去超市买了一个用塑料盒子装的带有塑料封膜的团子，那么我需要将塑料盒子和竹签子洗净后丢进可燃垃圾，封膜丢进塑料容器包装，如果丸子没吃完还要扔到厨余垃圾中。截至落笔时，我身旁还有一大堆等待拆分分类的垃圾。给我一个前半辈子没怎么做过垃圾分类的中国人以极大的震撼，因为我对这种分类体系和实施方案深感不解。所以本人决定以垃圾开篇，站在一个偏颇的视角分析日本或者说某一个方面的日本。

从垃圾的去向的角度来说，日本的垃圾分类体系的逻辑大概将垃圾分为三类，可燃垃圾，不可燃垃圾和资源垃圾。其中可燃垃圾顾名思义就是将会进入焚化炉焚烧的垃圾，所有被污染的垃圾，比如脏了的纸巾或是脏了的塑料盒子之类无法回收的垃圾会被焚烧。而资源垃圾则相反，是指有再利用可能的垃圾，例如塑料瓶，金属罐或是一些塑料袋之类的有可能回收的垃圾。不可燃垃圾由于接受一些碎掉的陶瓷，玻璃等无法被回收或是被燃烧处理的垃圾。所以基本上只能选择填埋。在填埋之前，一般会破碎后分离一些仍然可以回收的金属然后才是进入填埋。所以日本的垃圾基本上可以分成可回收和不可回收两个大类。日本居民每天需要分类的垃圾高达几十种，比如塑料瓶子的标签和盖子要和塑料瓶本身分开丢，牛奶的盒子需要洗干净展开晾干之后才能回收，如果是带有塑料瓶盖的牛奶，则需要将塑料瓶盖拆下来分开丢。雨伞要将伞面和骨架拆开后丢弃等。十分的繁琐并且耗费时间，即使是我一个人产生的垃圾，如果需要完全按照手册进行分类，其工作量不亚于整理房间。如果不分类会怎么样呢？根据《廃棄物の処理及び清掃に関する法律》（通常称《廃棄物処理法》或废弃法），对于违反“不法投弃”规定的，法定处罚可以达到5年以下拘禁、1000万日元约合50万元人民币以下的罚金，或者两者并处。当然这是diplomatic的文件，市政府或是各个行政单位有权根据这个法条制定适合当地垃圾处理政策，现实中如果不分类垃圾，垃圾处理人员有权利拒绝处理垃圾，即不收走你的垃圾。如果屡次拒绝分类则会下发正式的整改通知，如果继续则可能面临5万日元约合2500人民币以下的罚金。所以在日本街道上经常能够看到一些住户会在门前挂上大大的写有非法投置是犯罪的小牌子。但若是将垃圾扔在公共区域或是别人的财产上，则会触发废弃法的重拳出击。

那么如此严密的垃圾分类带来了什么好处吗？答案是很难评，因为首先，从一个横向的角度来说，日本的垃圾处理并没有与其分类难度相匹配的回报。日本的垃圾分类相关的法条主要制定于1970年至1995年这段时间左右，当时日本面临的主要问题实际上非常扭曲，即如何在不增加垃圾填埋场数量的情况下处理日益增长的垃圾。根据1993年日本国会上出现过的测算，全国的垃圾填埋场约全国剩余容量约 1.493亿 m³，还能处理大约未来8.1年内产生的垃圾，首都都市圈的填埋场还能处理大约5年的未来垃圾。1993年的环境白书写的是，新填埋场困难主要来自：“与自然环境保护的冲突，以及当地居民难以接受新场址。”，这是一个相当日本式的问题，即居民难以接受。在日本，似乎任何政策总会有这种“一些居民 难以接受”的问题，而这些问题又总是能够凌驾于所有的考量之上决定政策的生死。结果上来说，垃圾填埋场的建设在抛弃一些不宜施工的地方，一些环境需要保护的地方，一些居民无法接受的地方，一些距离过远的地方，一些国家战略不允许的地方，一些交通不方便的地方（因为要日本的垃圾卡车方便进出），一些地价过高的地方*，一些不出售的私人土地之后，日本政府面临的选择几乎就只剩下减少填埋垃圾了。政府的考量在当时是非常有道理的因为1970年前后的日本正处在经济高速发展的大环境下，1980年前后日本的地价就像是坐火箭一样起飞了，东京23区的地价号称能够买下整个美国。想要在东京都搞到一块地用于垃圾填埋，那么填埋在这里的垃圾的价值和地租一平均之后跟黄金差不了多少。并且一块地填埋的垃圾是有限的，如果政府需要一直不停的买地用以处理垃圾，那么这笔开支在1980年的日本将会是天文数字。所以日本一直在尝试使用垃圾填海造陆，尽管可能会造成污染。现在会有很多人说日本如此分类是因为日本国土狭小，土地资源紧张，所以必须细致处理。日本全国真正被建筑和道路直接占据的土地，大约只有国土的百分之九左右，所以这种观点实际上是偏颇的。为了解决垃圾填埋场的问题，日本政府的选择是将垃圾进行二次处理后再进行填埋，比如先破碎焚烧之后再选择填埋。为此催生了第一代的垃圾分类法案，其主要区分的是可燃垃圾和不可燃垃圾，垃圾按照处理程序的不同而不同。值得注意的是，这种以垃圾废弃处理为导向的垃圾分类并未区分我们现在能够看到的瓶是瓶，罐是罐的分类，而是粗暴的将垃圾划分为可燃，不可燃，和粗大垃圾以及推行后才出现的资源垃圾。这套体系的优点是明确的设计思路和可执行性，居民只需要按照常识以及一些引导进行分类即可。这套分类方法很难出现诸如剩饭剩菜还能堆肥种地，所以厨余垃圾属不属于资源垃圾之类的问题。此时的垃圾分类还称得上是纯良，至少我们能够看到其中的逻辑。在此之后，日本政府的垃圾填埋场的问题依旧没有得到根本解决，以至于1990年之后陆续出台了数个更加细致的垃圾分类法案。这里这里我就不在此赘述了，现今的垃圾分类体系如此庞大的一大功臣之一就是2000年通过的《循环型社会形成推进基本法》引入了一项舶来品，拡大生産者責任（Extended Producer Responsibility, EPR）原则。这项制度的核心思想是，垃圾不只是居民制造的，也是生产者制造的。所以不只是居民，产品的生产者也理应要对垃圾的产生负有责任。简而言之就是居民扔垃圾无罪，政府处理不了也无罪，但是这些垃圾本来就是企业制造的，所以企业有罪。于是政府规定，企业在生产后，对于流入市场上的可回收的垃圾存在回收义务（准确的来说的再商品化义务及其费用）。日本政府会根据一个企业生产的产品数量，种类以及比例为企业划定所需承担的回收费用，然后收取回收所需的费用。这个钱一般由企业按照法条提供的详细公式自己计算然后交给日本容器包装回收协会（日本容器包装リサイクル協会，JCPRA）并由其完成转交给pet等材料的回收厂家。这种模式在经济上更像是一种公益税。为了配合后续出台的各种各样的法条和规定，居民的垃圾分类制度已经在第一版可燃不可燃的基础上多次反复叠加，并最终形成了如今日本的垃圾分类体系。如今的垃圾分类体系主要是三种分类逻辑的混合制度。处理逻辑分类，材料逻辑分类，以及法律责任逻辑分类。分别是，按照可燃不可燃的处理逻辑分类的垃圾，按照材料能否回收的材料逻辑，以及方便企业进行再商品化的法律责任逻辑。一个瓶子可以同时是可燃垃圾，可回收垃圾以及再商品化垃圾。一个塑料盆属于可燃垃圾，但是同样材质的洗发水瓶子就是可回收或是再商品化垃圾。就现在的分类制度和垃圾处理体系而言，基本上只分可回收垃圾和不可回收垃圾，可回收垃圾会被简单处理之后回收利用。不可回收垃圾则会被破碎后焚烧，然后填埋。其中也包括所谓的不可燃垃圾，即使写着不可燃其结局也依然是被焚烧然后填埋。

相比之下，中国的制度就合理很多，中国目前实行的是垃圾和回收站的双轨模式。在中国，废弃的纸箱，塑料瓶，易拉罐，各类金属和纸张等都是可以拿到回收站换取报酬的。报酬基本上略低于该材料的市场价格，十分的市场化。这使得在任何环节都可以一定程度上分类垃圾，可以是居民自己整理拿去回收，也可以是保洁阿姨或是保安整理拿去回收，甚至是垃圾车上的工人拿去回收。很难想象一个社会主义国家使用了比资本主义国家还市场化的方案。这套方案虽然市场化，但是缺乏强制性，这就导致了中国实际上仍然有很多可被回收的垃圾被用于焚烧。关于焚烧的部分，根据2022年的数据，中国的垃圾焚烧比例高达百分之八十，在一些配备更新的汽轮机和焚化炉的地区甚至高达百分之九十以上，只有非常有限的垃圾进入填埋。另外，中国的垃圾处理非常的规模化，总体处理能力能够达到几十倍的差别。日本截至2025年有991座垃圾焚化装置，全国总处理能力约为17.35万吨每日。而中国光是西安市一地， 2024年的五座主要焚烧厂，单厂设计规模分别达到2250～3000 吨每天合计11250吨。就人均垃圾焚烧总量而言，按照2024年的数据粗略计算后，若将中国城市和县城的2.68亿吨焚烧量按全国人口摊算，则约为0.52 kg/人每日；同样计算日本全国一般废弃物直接焚烧量约为0.66 kg/人每日。按这一并非完全同口径的粗略指标，日本约高26%。中国的人均焚烧量甚至低于垃圾严格分类的日本，而日本的统计口径甚至只计算了直接焚烧而没有破碎后焚烧的垃圾。也就是说，纸面上日本人均实际焚烧量大约是中国的1.25～1.26倍。而在热力发电这方面由于中国起步较晚，有强大的后发优势本文就不在此比较了。毕竟日本开始垃圾分类时中国才刚刚结束文蛤。对于环保的标准，两国差别也不大，只是就总量来说中国人口和地域问题所以排放量远大于日本。对于居民来说，中国的垃圾分类的执行明显更加合理，将有经济价值的垃圾和低价值垃圾分开。然后可以换取报酬明显优于日本的不分类就罚款，在分类动机上更加人性化。对于垃圾的处理来说，中国垃圾的处理显得更加规模化和产业化。这里强调一下焚化能力是因为除了焚化能力外，日本几乎在所有垃圾处理能力的纸面数据上都与中国有相当差距。甚至在回收率上也是如此，在钢铁和纸张的回收上甚至是中国显著高于日本。但是考虑到中国的后发优势，这里就不再反复强调了。

最后，日本的垃圾分类政策由此观之，路径依赖的成分要高于其实际的效用。更细致的垃圾分类并没带来明显更少的焚烧量和更高的利用率，反而带来了更低的热力发电能力和居民端以及市镇的垃圾处理成本。简而言之，更细致的分类并没有带来更低的焚烧或是更高的回收利用，反而导致了更多的社会成本问题。相比于中国原则上分类但是灵活执行的制度，日本的制度将过分多的成本分配给了居民。并且这种分配是强制性的被enforcement强迫执行的，日本的垃圾属于每家分散，各家收集的分布。对于大多数一户建居民而言，其垃圾总是被堆放在最显眼的地方的，例如街道旁边，甚至就在正门。垃圾在一定程度上构成了这一家人的脸面，如果垃圾车没有收走垃圾，那么这一家人的垃圾就会暴尸荒野。就像是上个世纪的美国草坪文化一样，邻居之间比拼谁家的草坪跟整齐好看，更加茂盛。草坪更好看意味着时间越多，越富裕。而日本的垃圾也有同样的效果，但不同的是，日本的垃圾是不可选的。而是一种我穿了内裤式的道德审查，即由市镇人员审查，也由邻居审查。垃圾本应该是一种比较私密的产出物，而日本的垃圾不仅要求放在路边展示，还要求产出人进行分类。就像高中军训时叠豆腐块被子一样，豆腐块被子是一种符号，一种内务整洁，严格要求的中介物。被子本来应该是一个人休息的地方，休息意味着放松，不被审查。但是也正是这种不被，或者说不该被审查的地方的整洁才优于其它地方的整洁，所以豆腐块在一个要求纪律的地方是必要的。可军训只持续几个月，垃圾分类可能要持续一辈子。
